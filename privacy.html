Política de Privacidade

Esta Política de Privacidade descreve como as informações são tratadas no aplicativo Copa Brasil - O Jogo.

1. Coleta de informações

O aplicativo pode coletar automaticamente algumas informações não pessoais, incluindo:

  • Tipo de dispositivo
  • Sistema operacional
  • Dados de uso do aplicativo
  • Identificadores de publicidade (ID de anúncios)

2. Uso das informações

As informações coletadas são utilizadas para:

  • Melhorar o funcionamento do aplicativo
  • Analisar desempenho
  • Exibir anúncios relevantes

3. Publicidade (Unity Ads)

O aplicativo utiliza serviços de publicidade fornecidos pela Unity Ads.

A Unity pode coletar e processar dados como identificadores de dispositivo e dados de uso para personalizar anúncios.

Para mais informações, consulte a política da Unity:

https://unity.com/legal/privacy-policy

4. Base legal (GDPR)

Para utilizadores na União Europeia, o tratamento de dados é baseado em:

  • Consentimento do utilizador
  • Interesse legítimo para funcionamento do app

5. Direitos do usuário

Você pode:

  • Solicitar acesso aos seus dados
  • Solicitar exclusão dos dados
  • Desativar anúncios personalizados nas configurações do dispositivo

6. Compartilhamento de dados

Os dados podem ser compartilhados com serviços de terceiros apenas para funcionamento do aplicativo, como a Unity Ads.

7. Segurança

Adotamos medidas razoáveis para proteger as informações.

8. Alterações

Esta política pode ser atualizada periodicamente.
